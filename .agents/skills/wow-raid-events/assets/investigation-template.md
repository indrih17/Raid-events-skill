# Investigation title

## Question

Define the measured quantity and scope.

## Provenance

Date, source SHA, binary hash/build, game data, live/PTR, player/spec, profile/gear/IDs, expanded input, settings, commands, reports and missing artifacts.

## Observations

Metrics, units, owners, aggregation and exposure. Separate raw data from derived ratios.

## Checked code

Claim, path/function/SHA permalink, execution conditions and runtime confirmation.

## Controls

One changed factor and checks that distinguish competing explanations.

## Conclusion and evidence level

What is established, for which conditions, at which evidence level.

## Hypotheses and unknowns

Remaining mechanisms and missing data.

## Reproduction

Inputs, commands, artifact paths and parsing/simulation status.

## Next test

A test for which the remaining hypotheses predict different outcomes.
