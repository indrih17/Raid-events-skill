## Useful additions

Preserve a repeatable result with inputs/build/controls, a source fact with a SHA permalink, a reconstructed log timeline with observation bounds, or a confirmed model/interpretation limitation. Apply [evidence levels](evidence-rules.md) per claim. A source fact does not alone establish a cause. Incomplete historical observations remain explicitly limited; hypotheses belong to open questions, not established guidance.

Keep the skill focused on reusable WoW encounter workflows. Do not add one-off item/mechanic investigations to its default instructions without a user request. Avoid duplicated chapters and chat transcripts.

## Update procedure

1. Update the relevant reference or add a useful case study with provenance. Keep SKILL.md concise.
2. Record the question, date, source/build/game data, inputs, metric definitions, commands, controls, conclusion and limits. List unavailable artifacts rather than inventing them.
3. Correct superseded guidance with an explanation in provenance. Version differences do not invalidate historical observations. Keep source/original-methodology.md byte-for-byte unchanged; Git history preserves removed investigations.
4. Publish only the necessary reproduction material and safe aggregates. This authorization does not cover personal raw logs, tokens or identifying data. Document anonymization when used.
5. Check remote, branch, local edits and current main. Preserve other work; do not force push. Check links and repository validation. For script changes run unittest and relevant invalid-input/schema/arithmetic/ambiguity checks.
6. Commit only relevant files, perform an ordinary push and verify the remote commit. On failure preserve local work and report the concrete blocker.

Changes to an installed copy do not update GitHub. Use the canonical checkout. Sync a separately installed copy only if its path is known, preserving local edits; do not claim it was updated without checking. Report useful additions and the published commit briefly. No new verified knowledge means no research entry is needed.
