# Название расследования

## Проверяемый вопрос
Определи конкретную величину и scope.

## Provenance
Дата; source SHA; binary build/hash; game build; live/PTR; player/spec; gear/set/IDs; expanded input; seed/threads/iterations; команды; reports; missing artifacts.

## Наблюдения
Таблица mean E/R/ticks/damage/exposure, units и scope. Отдельно raw data и derived ratios.

## Проверенный код
Claim → path/function/SHA permalink → execution conditions → runtime confirmation.

## Контроли
Одна изменяемая переменная; controls с другой target count, ordering, state, geometry или model.

## Вывод и уровень
Что доказано. Уровень каждого claim по evidence-rules.md.

## Гипотезы и неизвестное
Неисключённые механизмы и отсутствующие данные.

## Воспроизведение
Полные inputs, commands и artifact paths. Статус parsing/simulation.

## Следующая проверка
Эксперимент, дающий разные предсказания competing hypotheses.
